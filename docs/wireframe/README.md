# ポートフォリオ ワイヤーフレーム

`index.html` をブラウザで開くと、操作可能な低忠実度ワイヤーフレームを確認できます。

> **これは着手時点の記録です。** 実装はこのあと変わっているので、現状は
> リポジトリ直下の [README](../../README.md) を参照してください。
> 主な違い: Home のキービジュアルと About のポートレート枠は削除、
> Works はサムネイルをやめて文章主体、Skills は3列の縦リストに変更。

## 前提条件

| 項目       | 決定                                                                 |
| ---------- | -------------------------------------------------------------------- |
| 形式       | SPA（画面遷移なし・URL は hash で同期）                              |
| トーン     | モダン / シンプル                                                    |
| スクロール | **なし**（`html, body { overflow: hidden }` + 全画面 `100dvh` 固定） |
| レイアウト | 固定サイドナビ + 差し替え式ペイン                                    |
| セクション | Home / About / Works / Skills / Contact（5画面）                     |
| 配色       | ライト・ダーク切替対応                                               |

## 全体レイアウト

```
┌──────────────┬────────────────────────────────────────┐
│  260px       │  1fr                                    │
│  固定ナビ     │  差し替えペイン（クロスフェード）        │
│              │                                         │
│  [ IMG ]     │  ┌ 01 — HOME ─────────────────────┐     │
│  NAME        │  │ ラベル + 見出しバー             │     │
│  role        │  ├────────────────────────────────┤     │
│              │  │                                │     │
│  ● HOME   01 │  │  panel-body（可変高さ 1fr）     │     │
│  ○ ABOUT  02 │  │                                │     │
│  ○ WORKS  03 │  │                                │     │
│  ○ SKILLS 04 │  ├────────────────────────────────┤     │
│  ○ CONTACT05 │  │ 補足ラベル          [ ← ][ → ] │     │
│              │  └────────────────────────────────┘     │
│  ◐ THEME     │                              01 / 05    │
│  [GH][X][IN] │                                         │
└──────────────┴────────────────────────────────────────┘
                 高さは常に 100dvh。ページ全体は絶対にスクロールしない
```

- **左ペインは不変**。ページ全体を再描画せず、右ペインだけが切り替わる → SPA らしい体験。
- 右ペインは全パネルを CSS Grid の同一セルに重ね、`opacity` + `translateY` でクロスフェード。
- 各パネルは `head`（固定）/ `body`（`flex: 1` で可変）/ `foot`（固定）の3層。
  **body だけが伸縮する**ので、どの画面高でも溢れない。

## 各セクションの構成

### 01 Home — 2カラム（1.15fr : 0.85fr）

挨拶ラベル → 大見出し2行 → 補足テキスト → CTA 2つ（VIEW WORKS / CONTACT）。
右にキービジュアル（`min(58vh, 420px)`）。

### 02 About — 2カラム（260px : 1fr）

左にポートレート（縦いっぱい）。右は Profile 段落 + Career タイムライン（3〜4行）。

### 03 Works — 3 × 2 グリッド

1画面に**6件まで**。カードはサムネイル（`1fr`）+ タイトル + タグ。
7件目以降はフッタのページャで送る（スクロールさせない）。

### 04 Skills — 3カラム

Frontend / Backend / Tools の3グループ。各項目は名称 + 4px のメーターバー。

### 05 Contact — 2カラム

左に見出し + Email + SNS。右に NAME / EMAIL / MESSAGE + SEND ボタン。

## ナビゲーション

| 操作                 | 動作                    |
| -------------------- | ----------------------- |
| サイドナビのクリック | 該当セクションへ        |
| `←` `↑` / `→` `↓`    | 前後のセクションへ      |
| フッタの `←` `→`     | 前後のセクションへ      |
| URL hash             | `#works` などで直接復元 |

## スクロールを発生させないための設計ルール

1. ルートは `height: 100dvh` + `overflow: hidden`。
2. Grid/Flex の子には必ず `min-height: 0` / `min-width: 0` を付ける（既定の `min-content` が溢れの原因）。
3. 可変長コンテンツ（Works）は**件数を固定**し、超過分はページャに逃がす。
4. 余白は `clamp(24px, 3.2vw, 56px)` でビューポート連動。
5. 1024px 未満ではサイドナビを上部バーに切り替え、写真・キービジュアルを隠して1画面に収める。
